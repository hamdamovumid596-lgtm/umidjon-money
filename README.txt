UMIDJON MONEY — ishga tushirish

1) ZIP ichidagi fayllarni bitta papkaga chiqaring.
2) Bepul HTTPS hostingga joylang (masalan GitHub Pages).
3) iPhone'da Safari orqali saytni oching.
4) Share (Ulashish) → Add to Home Screen (Bosh ekranga qo‘shish) ni bosing.

Ma'lumotlar shu iPhone brauzerining local storage xotirasida saqlanadi.
Safari ma'lumotlarini tozalashdan oldin Hisobot → Zaxira nusxasini yuklab olish orqali JSON nusxa oling.
Bu dastur bank hisoblariga ulanmaydi; barcha yozuvlar qo‘lda kiritiladi.
